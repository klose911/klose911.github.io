流式传输是构建响应式应用程序的关键。可能需要流式传输以下几种类型的数据：
+ [[https://langgraph.com.cn/agents/streaming/index.html#agent-progress][代理进度]] ：在代理图中的每个节点执行后获取更新
+ [[https://langgraph.com.cn/agents/streaming/index.html#llm-tokens][LLM 令牌]] ：在语言模型生成令牌时进行流式传输
+ [[https://langgraph.com.cn/agents/streaming/index.html#tool-updates][自定义更新]] ：在执行过程中从工具发出自定义数据（例如，“已获取 10/100 条记录”）

可以同时流式传输[[https://langgraph.com.cn/agents/streaming/index.html#stream-multiple-modes][多种类型的数据]]
