* 创建一个 StateGraph
#+begin_example
现在可以使用 LangGraph 创建一个基本聊天机器人。这个聊天机器人将直接回复用户的消息。
#+end_example

首先创建一个 _StateGraph_ 。一个 StateGraph 对象将聊天机器人结构定义为 *状态机*
1. 添加 *节点* 来表示 LLM 和聊天机器人可以调用的函数
2. 添加 *边* 来指定机器人应如何在这些函数之间进行转换

#+begin_src python 
  from typing import Annotated

  from typing_extensions import TypedDict

  from langgraph.graph import StateGraph, START
  from langgraph.graph.message import add_messages


  class State(TypedDict):
      # Messages have the type "list". The `add_messages` function
      # in the annotation defines how this state key should be updated
      # (in this case, it appends messages to the list, rather than overwriting them)
      messages: Annotated[list, add_messages]


  graph_builder = StateGraph(State)
#+end_src

现在可以处理两个关键任务
+ 每个 _节点_ 都可以 *接收* 当前 _状态_ 作为输入，并 *输出* _状态的更新_
+ 对 _消息_ 的更新将 *追加* 到现有列表而不是覆盖它
  #+begin_example
    这得益于与 Annotated 语法一起使用的预构建 add_messages 函数
  #+end_example

定义图时：第一步是定义其 *状态* 。状态 包括图的模式和处理状态更新的 reducer 函数

#+begin_example
  在我们的示例中，状态 是一个具有一个键：messages 的 TypedDict

  add_messages reducer 函数用于将新消息追加到列表中，而不是覆盖它

  没有 reducer 注解的键将覆盖先前的值
#+end_example

要了解有关状态、reducer 和相关概念的更多信息，请参阅 [[https://langgraph.com.cn/reference/graphs/index.html#langgraph.graph.message.add_messages][LangGraph 参考文档]] 
* 添加一个节点
接下来，添加一个“chatbot”节点。 *节点* 表示工作单元，通常是普通的 Python 函数

首先选择一个聊天模型：
#+begin_src python 
  import os
  from langchain.chat_models import init_chat_model

  os.environ["ANTHROPIC_API_KEY"] = "sk-..."

  llm = init_chat_model("anthropic:claude-3-5-sonnet-latest")
#+end_src

现在可以将聊天模型集成到一个简单的节点中

#+begin_src python 
  def chatbot(state: State):
      return {"messages": [llm.invoke(state["messages"])]}


  # The first argument is the unique node name
  # The second argument is the function or object that will be called whenever
  # the node is used.
  graph_builder.add_node("chatbot", chatbot)
#+end_src

注意 _chatbot 节点函数_ :
+ 将当前 *状态* 作为 _输入_
+ 返回一个包含更新的 *消息* 列表的 _字典_
  + 键为 _messages_ 

#+begin_example
这是所有 LangGraph 节点函数的基本模式
#+end_example

_状态_ 中的 *add_messages* 函数会将 _LLM 的响应消息_ *追加* 到 _状态中已有的消息之后_

* 运行聊天机器人
#+begin_example
可以随时通过键入 quit、exit 或 q 来退出聊天循环
#+end_example

#+begin_src python 
  def stream_graph_updates(user_input: str):
      for event in graph.stream({"messages": [{"role": "user", "content": user_input}]}):
          for value in event.values():
              print("Assistant:", value["messages"][-1].content)


  while True:
      try:
          user_input = input("User: ")
          if user_input.lower() in ["quit", "exit", "q"]:
              print("Goodbye!")
              break
          stream_graph_updates(user_input)
      except:
          # fallback if input() is not available
          user_input = "What do you know about LangGraph?"
          print("User: " + user_input)
          stream_graph_updates(user_input)
          break
#+end_src
