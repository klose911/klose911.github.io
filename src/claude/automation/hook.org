#+begin_example
  当 Claude Code 编辑文件、完成任务或需要输入时自动运行 shell 命令

  格式化代码、发送通知、验证命令并强制执行项目规则
#+end_example

Hooks 是用户定义的 shell 命令，在 Claude Code 生命周期中的特定点执行。它们对 Claude Code 的行为提供确定性控制，确保某些操作始终发生，而不是依赖 LLM 选择运行它们。使用 hooks 来强制执行项目规则、自动化重复任务，并将 Claude Code 与现有工具集成

#+begin_example
  有关扩展 Claude Code 的其他方式，请参阅 skills 用于为 Claude 提供额外的指令和可执行命令

  subagents 用于在隔离的上下文中运行任务，以及 plugins 用于打包要在项目间共享的扩展
#+end_example

对于需要判断而不是确定性规则的决策，也可以使用 [[https://code.claude.com/docs/zh-CN/hooks-guide#prompt-based-hooks][基于提示的 hooks]] 或 [[https://code.claude.com/docs/zh-CN/hooks-guide#agent-based-hooks][基于代理的 hooks]]，它们使用 Claude 模型来评估条件
