#+begin_example
  在单独的 git worktrees 中隔离并行 Claude Code 会话，以便更改不会相互冲突

  涵盖 --worktree 标志、子代理隔离、.worktreeinclude、清理和非 git VCS hooks
#+end_example

[[https://git-scm.com/docs/git-worktree][git worktree]] 是一个单独的工作目录，具有自己的文件和分支，但与主检出共享相同的存储库历史和远程
#+begin_example
  在自己的 worktree 中运行每个 Claude Code 会话意味着一个会话中的编辑永远不会触及另一个会话中的文件

  因此可以让 Claude 在一个终端中构建功能，同时在第二个终端中修复错误
#+end_example

本页涵盖 CLI 中的 worktree 隔离。下面的所有内容都假设使用 git 存储库

#+begin_example
  对于其他版本控制系统，请参阅非 git 版本控制

  桌面应用会为每个新会话自动创建一个 worktree
#+end_example

Worktrees 是运行 Claude 并行的几种方式之一。它们隔离文件编辑，而子代理和代理团队协调工作本身
